# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop built with React and Redux.

## Features

- Browse plants by category
- View plant names, descriptions, images, and prices
- Add plants to the shopping cart
- Increase or decrease item quantities
- Remove items from the cart
- Dynamically calculate cart totals
- Responsive navigation between Home, Plants, and Cart

## Technologies Used

- React
- Redux Toolkit
- React Router
- CSS
- JavaScript
